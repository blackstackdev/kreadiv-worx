## Implement now

1. One dominant promise: find exact copies without surrendering control.
2. Real v1.0.4 screens and one acceptance-run receipt instead of generic storage imagery.
3. Planned price and licence stated beside the exact reasons checkout is still closed.
4. Privacy, safety, limitations, support, and publisher credit reachable from the page.

## Deliberately rejected

- Countdown timers, inflated percentage discounts, gifts, and fake scarcity.
- Claims that every duplicate is safe to remove.
- A generic cleaner aesthetic or cloud dashboard for a local Windows utility.
- Public source-code or build hosting on GitHub.
- A live payment button before seller terms and test delivery are complete.
