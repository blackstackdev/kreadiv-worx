Try it

  1. Install and run the Windows host. Keep the PC running on the same trusted private Wi-Fi as the phone.
  2. Create a pairing link in the host. Use Enter Portal Link in the Android app. Google services and GBox are not required for manual pairing.
  3. Choose a fictional file on the phone and send it to the PC. Open the received file.
  4. Send a fictional file from the PC, download it on the phone and open it. Compare its contents.

Windows 10/11, 64-bit, and Android 8+ are supported. Windows installers are unsigned. Files are limited to 2 GiB each. Ordinary LAN HTTP is unencrypted; use trusted networks. Optional private HTTPS requires separate configuration. The Windows host is required, including for phone-to-phone handoffs. Updates are manual.
